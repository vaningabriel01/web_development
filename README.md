Formulário Interativo com PHP (Method POST)
Este projeto consiste em uma aplicação web simples desenvolvida para demonstrar a manipulação de dados enviados via formulário utilizando o método POST em PHP. Os dados inseridos pelo usuário são processados e exibidos dinamicamente nas páginas de destino.

 Funcionalidades
Captação de Dados: Formulário estruturado para coletar informações do usuário.

Processamento de Dados: Uso do método global $_POST do PHP para recebimento seguro das informações.

Exibição Dinâmica: Os arquivos index.php e contato.php atuam no processamento e retorno visual dos dados enviados.

 Tecnologias Utilizadas
HTML5: Estruturação das páginas e do formulário.

CSS3: Estilização básica para interface do usuário.

PHP: Lógica de backend para recepção e exibição dos dados.
