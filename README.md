Validação Dinâmica e Submissão Assíncrona (JS/Async)
Este projeto apresenta uma interface de formulário inteligente que utiliza JavaScript Moderno para garantir a integridade dos dados e melhorar a fluidez da página. A aplicação impede o envio de dados incompletos e utiliza funções assíncronas para atualizar o conteúdo da tela sem a necessidade de recarregar a página (reloading).

 Diferenciais do Projeto
Validação em Tempo Real: Uma função dedicada monitora os campos do formulário, habilitando o envio apenas quando todos os requisitos de preenchimento são atendidos.

Comunicação Assíncrona (async/await): Utiliza funções assíncronas para processar os dados.

Manipulação do DOM: O conteúdo da página é alterado dinamicamente via JavaScript.

🛠️ Tecnologias e Conceitos
JavaScript (ES6+): Uso de Arrow Functions, Promises e Async/Await.

CSS Dinâmico: Feedback visual para campos válidos/inválidos e estado do botão de envio.
