# 📋 Projeto 02 - Validação de Formulário

Este projeto tem como objetivo validar o preenchimento de um formulário utilizando JavaScript.

## 🚀 Funcionalidade

Foi desenvolvida uma função em JavaScript que verifica se todos os campos do formulário foram preenchidos corretamente.  

Caso algum campo não esteja preenchido, o sistema exibe um alerta informando quais campos precisam ser completados.

## 🛠️ Tecnologias utilizadas

- HTML  
- CSS  
- JavaScript
